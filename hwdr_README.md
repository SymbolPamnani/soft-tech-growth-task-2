# Handwritten Digit Recognition

This project recognizes handwritten digits (0-9) using a Convolutional Neural Network trained on the MNIST dataset.

## 🎯 Features
- Loads MNIST dataset automatically
- CNN model with 98%+ accuracy
- Interactive drawing pad to test your own handwriting
- Visualizes predictions

## 🚀 How to Run
1. Open in Google Colab
2. Run all cells
3. Draw a digit in the canvas
4. Click "Predict Digit" to see the result
5. If want to predict another digit, just click clear and draw again then click predict

## 📊 Results
- Test Accuracy: ~98-99%
- Training time: 2-3 minutes

## 🛠️ Technologies
- TensorFlow/Keras
- Python
- Google Colab
- OpenCV/PIL

## About
This project implements a CNN model to recognize single handwritten digits (0-9) using the MNIST dataset.

## Note
This model recognizes SINGLE digits only, as per project requirements.
